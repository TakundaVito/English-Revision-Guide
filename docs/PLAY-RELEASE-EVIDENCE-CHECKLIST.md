# English Prep release evidence checklist

| Gate | Evidence | Owner | Status |
|---|---|---|---|
| Curriculum | Teacher review and signed correction log | Curriculum reviewer | Pending |
| IP/content | Asset register, licences and assignments | Owner/legal adviser | Pending |
| Privacy | Approved policy, data map and guardian process | Privacy/legal adviser | Pending |
| Deletion | In-app and public deletion test evidence | Engineering/owner | Pending |
| Signing | Upload-key fingerprint and secure custody record | Account owner | Pending |
| Build | Signed AAB checksum and version code | Engineering | Pending |
| Listing | Copy, icon, screenshots and feature graphic | Store owner | Pending |
| Reviewer access | Dedicated learner credentials and instructions | Store owner | Pending |
| Closed test | Tester list, opt-in date and issue log | Pilot owner | Pending |
| Production | Play production-access approval | Google Play | Pending |

Never put passwords, private keys, guardian identity documents or learner
personal data in this checklist or in Git.
