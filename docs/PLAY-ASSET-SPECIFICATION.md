# English Prep Play asset specification

Use real screenshots from the signed candidate build. Do not create synthetic
screenshots or show real learner data.

## Capture set

Capture a clean phone-sized device in English showing:

1. Home and Paper 1/Paper 2 lesson navigation.
2. A lesson with a worked example and checklist.
3. A practice question with explanation and progress state.
4. Accessibility settings and readable text-size controls.
5. Optional coach/scanner only if enabled in the uploaded build.

## Quality bar

- Use the current release version and package.
- Use seeded, fictional data only.
- Remove notification bars, personal accounts, tokens and debug overlays.
- Keep text legible at Play Console’s phone screenshot dimensions.
- Use the same screenshot order in the listing and reviewer instructions.
- Store the source captures and checksum in the release evidence folder.

## Still required from the owner

- Approved 512x512 launcher icon and 1024x500 feature graphic if requested.
- Device/emulator screenshots from the candidate build.
- Confirmation that all visible curriculum and branding assets are licensed.
